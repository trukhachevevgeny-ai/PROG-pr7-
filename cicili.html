Программа Цикл. Повторение действий несколько раз

Цикл заставляет программу выполнять одно и то же действие несколько раз. Перетащите кружок в серую зону 3 раза — и цикл завершится.

Итерации цикла
Повторений: 0 из 3
program Loop;

{ Простейший цикл: повторить 3 раза }

var
  i : integer;

begin
  for i := 1 to 3 do
    writeln(i);      { выводим номер шага }
end.
# Простейший цикл: повторить 3 раза

for i in range(1, 4):
    print(i)         # выводим номер шага
// Простейший цикл: повторить 3 раза
public class Loop {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println(i);   // выводим номер шага
        }
    }
}
